# ValuePlus System v1.0.43 — DR.DOOM

หน้า Login และ Splash ใช้ภาพแมว ValuePlus ฉากเดียวกัน พร้อมโทนเขียวมรกต–ทอง
ปรับพื้นการ์ด ปุ่ม ช่องกรอก ตาราง และหน้าต่างย่อยของ Dashboard และหน้าระบบงานให้เข้าธีมและอ่านข้อความได้ชัดเจน
แท็บลูกหนี้และลดหนี้ใช้สีเขียวและทองเข้ม แสดงสถานะที่เลือกด้วยขอบสีและป้ายกำลังใช้งาน

## การตรวจสอบ

- TypeScript และ Vite production build ผ่าน
- React server render หน้าเริ่มต้น 10 หน้า ผ่าน
- ตรวจลำดับ CSS ของส่วนที่เคยเป็นสีขาวและแบบฟอร์ม/ตาราง/portal: 39 assertions ผ่าน
- ตรวจแท็บลูกหนี้/ลดหนี้จาก production CSS ทั้ง active/inactive และ hover: 8 กรณีผ่าน
- ตรวจ contrast ตัวอักษรของแท็บ: 6 คู่สีผ่านเกณฑ์ 4.5:1
- git diff --check ผ่าน

ข้อจำกัดการตรวจสอบ: ยังไม่ได้ตรวจภาพและการสลับแท็บจริงบน Windows/Tauri และไม่ได้ทดสอบการประมวลผลหรือบันทึกข้อมูลกับ backend ในงานแก้ธีมนี้
